# Hoe laat is dit?

Graad 6 oefenblad om tyd te lees (Afrikaans). Een `index.html`, geen aanmelding, geen databasis.

Vier maniere om te oefen:
1. Wysers → sê dit (hardop, dan wys die antwoord)
2. Wysers → tik digitaal
3. Digitaal → sê dit
4. Digitaal → trek die wysers

Skakelaars: Maklik (elke 5 min) / Moeilik (elke minuut), en 12-uur / 24-uur (vm / nm).

Woorde volg die klas se manier: "twintig oor drie", "vyf-en-twintig oor drie", "half vier",
"vyf-en-twintig voor vier". Die woorde-reëls is in `timeWords()` in `index.html`.
