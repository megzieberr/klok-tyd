# Project status — updated 2026-10-14
## Where we are
"Hoe laat is dit?" Gr6 Afrikaans time-reading page. One `index.html`, no login, no database.
LIVE at https://megzieberr.github.io/klok-tyd/ (GitHub Pages from `main`: a push IS the deploy).
Four modes, endless "Volgende", Maklik/Moeilik and 12-uur/24-uur (vm/nm) switches. All tested.

## Decisions
- 2026-10-14: each mode shows ONLY the clock the learner must read; the reveal shows both.
- 2026-10-14: no fixed rounds; learners click "Volgende" until tired, then go back and pick another mode.
- 2026-10-14: "sê dit" modes have no input: say it aloud, tap "Wys antwoord".
- 2026-10-14: words: "twintig oor drie", "vyf-en-twintig oor drie", "half vier" (two words), "vyf-en-twintig voor vier".
- 2026-10-14: on the hour = two words: "drie uur", "een uur".
- 2026-10-14: 24-uur mode uses vm (oggend) and nm (middag / aand).
- 2026-10-14: "trek" the hands, never "sleep".
- 2026-10-28: fifth card "Gemeng" mixes modes 1, 2 and 3 at random, one per question. Never mode 4 (trek wysers). Tally: "Tyd nr. N · Reg: x / y" (the score counts only the typed questions).
- 2026-10-14: "analoog klok" and "digitale klok", never "wyserhorlosie" / "digitale horlosie". Plain "horlosie" in "Jou horlosie" stays.
